The relay meters what it forwards, and starts on Windows (R66).

- A price table naming a model that searches on every call (`PER_CALL_MODEL`: an id ending `-search-preview` or `-search-api`, dated or not) is refused at provisioning and by the relay's own start. A search is billed outside the token counts the meter reads (#205).
- The `openai-responses` dialect reads the tier an answer reports, from the body and from `response.completed`, and stops forwarding after one served at any tier but `default`, as `openai-chat` does (#208).
- The relay's source is written to its container's standard input and is in no argument, so it no longer counts toward the Windows command-line limit. `AppliedRelay.runArgs` is now the `docker create` argv. `relayCreateArgs`, `windowsCommandLineLength`, and `WINDOWS_COMMAND_LINE_LIMIT` are exported, and each driver that ships a meter tests its own table against the limit (#207).
- New conformance entry `I5.model-relay-source-is-in-no-argument`; the openai-chat and openai-responses fail-closed entries gain the cases above.

+/**
+ * Starts a container created with `--interactive`, writing `input` to its
+ * standard input and closing it, which is how a program too long for a
+ * command line reaches `node -` with nothing mounted and no image built.
+ *
+ * `docker start --interactive` stays attached for as long as the container
+ * runs, so this returns at once and the caller decides when the container is
+ * up and releases the client. Everything the container prints is discarded
+ * here; `docker logs` keeps its own copy.

+export function dockerStartWithInput(executable: string, containerId: string, input: string): InputStart {
+  const child = spawn(executable, ['start', '--interactive', containerId], { shell: false, stdio: ['pipe', 'pipe', 'pipe'], windowsHide: true });
+  let failed: string | undefined;
+  let over = false;
+  let stderr = '';
+  const fail = (why: string): void => {
+    failed ??= why;
+  };
+  writeStdin(child.stdin, input, (error) => {
+    fail(`the program could not be written to the container's standard input: ${error.message}`);
+    child.kill('SIGKILL');
+  });
+  child.stdout.resume();
+  child.stderr.on('data', (chunk: Buffer) => {
+    if (stderr.length < START_STDERR_LIMIT) stderr += chunk.toString('utf8').slice(0, START_STDERR_LIMIT - stderr.length);
+  });

+    over = true;
+    fail(`${executable} could not be run: ${error.message}`);
+  });

+    over = true;
+    // A client this module killed reports a null code and is not a failure of the start.
+    if (code !== null && code !== 0) fail(`docker start exited ${String(code)}: ${stderr.trim()}`);
+  });

+    ended: () => over,

+/** One argument as Node writes it into a Windows command line (libuv's `quote_cmd_arg`). */
+function windowsQuoted(arg: string): string {
+  if (arg === '') return '""';
+  if (!/[ \t"]/u.test(arg)) return arg;
+  if (!/["\\]/u.test(arg)) return `"${arg}"`;
+  // Backslashes are literal unless a quote follows them, where each is doubled and the quote escaped; the closing quote counts as one.
+  let out = '"';

+  for (const ch of arg) {
+    if (ch === '\\') {
+      slashes += 1;
+      continue;
+    }
+    out += '\\'.repeat(ch === '"' ? slashes * 2 + 1 : slashes) + ch;
+    slashes = 0;
+  }

   /**

    * command inside the container, so the container goes, and with it the

     if (error instanceof CliOutputExceeded) {

     // A probe that already finished removed itself, so a failure here is not reported.
     await Promise.all([...probes].map((name) => this.#remove(name)));

     // while the sandbox runs can be overtaken by a process still calling the relay (D-P13-07).

       }
     }
     const sidecars = await this.#stopSidecars(controls.egress);
     return { removal: container ?? sidecars, reading, egress };
   }

    * failure has no caller to refuse: it is recorded on the sandbox, where the
    * next `exec` or `destroy` reports it, rather than raised as an unhandled
    * rejection.

   async #expire(sandbox: Sandbox, budgetMs: number): Promise<void> {
     if (sandbox.ending !== undefined) return;

     if (removal !== undefined) {

     }
   }
