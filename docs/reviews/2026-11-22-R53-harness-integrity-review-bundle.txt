The agent CLI is installed by content, and the evidence names the image every driver call ran in (R53, #169).

Each driver's image now installs its CLI from `image/cli-lock.json` (an npm lockfile, named so that a packed package carries it), which pins the CLI and every platform package by `sha512`, using `npm ci`. It never installs by name. npm skips an optional platform package whose tarball fails its hash, so `image/check-install.js` then fails the build unless every package pinned for the image's platform is installed as locked. `ensureImage` refuses a lockfile with an entry that has no `sha512` integrity, or that resolves outside the npm registry, or a lockfile whose CLI is not `CLI_VERSION`. It now returns the image's content ID instead of its tag. It refuses, and never rebuilds over, a tag the daemon holds as an image this host did not record building. The record is kept under `~/.factory/images/`, and `EnsureImageOptions.records` overrides that location.

`@olympus-ai/vault` adds `HarnessImage` and `harnessImage` on `UsageRecord` and `EvidenceBundle` (A-R53-01). Both Vaults refuse `not-recorded` and any ID that is not a content ID. `@olympus-ai/sandbox` adds `imageId()`, which pulls only when asked and only for a digest-pinned reference, `harnessLockProblems()`, and `recordedImage()`. In `@olympus-ai/api`, the line records the image it provisioned each call from, and a bundle copies the image from its build call's usage record. `buildGraph` refuses a profile whose `buildImage` or `driverImages` value is not a content ID. `readUsage` reads a record written before R53 as `not-recorded`.

New assertions: `I2.harness-image-recorded-by-the-runtime`, `I5.harness-image-unnamed-is-refused`, `I5.claude-code-image-installs-the-cli-by-content`, `I5.claude-code-image-replaced-is-refused`, `I5.codex-image-installs-the-cli-by-content`, and `I5.codex-image-replaced-is-refused`.

===== .changeset/retry-carries-validator-message.md =====
---
"@olympus-ai/core": minor
"@olympus-ai/api": patch
"@olympus-ai/conformance": patch
---

A sent-back draft's retry is told the validator's message, not only its code. A runtime problem in `DraftSendBack` and in the `runtime-problems` retry part gains an optional `message`, written where a validator read the draft alone (a drafted manifest's shape, a drafted spec's parts, a drafted observation plan) and rendered as `- path: code — message`, cut to 300 characters (`RETRY_MESSAGE_LIMIT`). Problems judged against the base keep their code only, and still reach a test drafter as one contentless `base-refusal`. Records written before this carry no message and read as before (A-R36b-01, #174). New assertion: `I3.retry-is-told-its-own-shape-mistakes`.

/** Every usage record the run wrote that is not a pending one, read back. */
async function calls(vault: Vault, refs: ReadonlyArray<Parameters<Vault['read']>[0]>): Promise<UsageRecord[]> {
  const records = await Promise.all(refs.map((ref) => readRecord<UsageRecord>(vault, ref)));
  return records.filter((r) => r.reading.kind !== 'pending');
}

    + "driver and never anything the driver returned; with no profile they name no-sandbox; and a usage record read from before R53 is not-recorded",
  run: async () => {
    const { readUsage, startRun } = await api();
    await withLine('r53-i2-', async (rig) => {
      // A reviewer through a driver of its own, so the profile provisions it from its own image (R9, D-R9-06).
      const reviewer = { ...(await stubDriver({ family: 'other-family' })), provenanceId: () => 'r53-reviewer@1' };

              const { harnessImage: _image, ...record } = JSON.parse(new TextDecoder().decode(bytes)) as UsageRecord;

            };

        },

===== packages/drivers/claude-code/image/check-install.js =====
// Run in the image build, after `npm ci`, and fails the build unless every
// package the lockfile pins for this image's platform was installed as locked
// (R53).
//
// `npm ci` checks each tarball against the lockfile's integrity, but a CLI's
// platform packages are optional dependencies, and npm skips an optional
// package whose tarball fails the check rather than failing the install. A
// probe build with one platform package's hash altered warned "seems to be
// corrupted" and succeeded, and the CLI then ran from a sibling package
// (D-R53-02). So the build does not trust npm's exit code alone: a package
// the lockfile names for this platform that is not installed at its locked
// version and integrity is a build failure that names the package.
//
// usage: node check-install.js <directory holding package-lock.json and node_modules>
/* global require, process -- run by node during the image build, never imported */
/* eslint-disable @typescript-eslint/no-require-imports -- a CommonJS script: the image runs it with plain node, before any package exists */
'use strict';

const { readFileSync } = require('node:fs');
const { join } = require('node:path');

const dir = process.argv[2];
if (dir === undefined) {
  process.stderr.write('usage: node check-install.js <dir>\n');
  process.exit(2);
}

const read = (path) => JSON.parse(readFileSync(path, 'utf8'));
const locked = read(join(dir, 'package-lock.json')).packages;
// npm's record of what it installed: written by `npm ci`, one entry per package on disk.
const installed = read(join(dir, 'node_modules', '.package-lock.json')).packages;

const libc = process.report.getReport().header.glibcVersionRuntime === undefined ? 'musl' : 'glibc';

// npm's platform fields: a list of allowed values, where `!x` excludes one.
function allows(list, value) {
  if (list === undefined) return true;
  const values = Array.isArray(list) ? list : [list];
  const allowed = values.filter((v) => !v.startsWith('!'));
  return (allowed.length === 0 || allowed.includes(value)) && !values.includes(`!${value}`);
}

const problems = [];
for (const [path, entry] of Object.entries(locked)) {
  if (path === '') continue;
  const forThisPlatform = allows(entry.os, process.platform) && allows(entry.cpu, process.arch) && allows(entry.libc, libc);
  const required = entry.optional !== true || forThisPlatform;
  const got = installed[path];
  if (got === undefined) {
    if (required) problems.push(`${path}@${entry.version} is pinned for ${process.platform}-${process.arch} and was not installed`);
    continue;
  }
  if (got.version !== entry.version || got.integrity !== entry.integrity) {
    problems.push(`${path} was installed as ${got.version} ${got.integrity}, not as locked, ${entry.version} ${entry.integrity}`);
    continue;
  }
  // The package on disk, not only npm's account of it.
  let onDisk;
  try {
    onDisk = read(join(dir, path, 'package.json')).version;
  } catch {
    onDisk = undefined;
  }
  if (onDisk !== entry.version) problems.push(`${path} on disk is ${String(onDisk)}, not ${entry.version}`);
}
for (const path of Object.keys(installed)) {
  if (path !== '' && locked[path] === undefined) problems.push(`${path} was installed and is not in the lockfile`);
}

if (problems.length > 0) {
  process.stderr.write(`check-install: the install does not match the lockfile, so the image is not built:\n${problems.map((p) => `  ${p}`).join('\n')}\n`);
  process.exit(1);
}
process.stdout.write(`check-install: ${String(Object.keys(locked).length - 1)} locked packages, every one for ${process.platform}-${process.arch} installed as locked\n`);

function testTag(): string {

/** The daemon's platform package: what the image's install must hold. */
async function platformPackage(): Promise<string> {
  const arch = await docker('info', '--format', '{{.Architecture}}');
  const cpu = arch === 'aarch64' || arch === 'arm64' ? 'arm64' : arch === 'x86_64' || arch === 'amd64' ? 'x64' : arch;
  return `${CLI_PACKAGE}-linux-${cpu}`;
}

interface Lock {
  readonly packages: Record<string, { readonly version?: string; readonly integrity?: string; readonly optional?: boolean; readonly os?: string[]; readonly cpu?: string[] }>;
}

async function lock(dir: string): Promise<Lock> {
  return JSON.parse(await readFile(join(dir, 'cli-lock.json'), 'utf8')) as Lock;
}

/** A copy of the build context whose lockfile pins `pkg` at a hash its tarball does not have. */
async function alteredContext(pkg: string): Promise<string> {
  const dir = await temp('r53-context-');
  await cp(imageContext(), dir, { recursive: true });
  const locked = await lock(dir);
  const entry = locked.packages[`node_modules/${pkg}`];
  if (entry?.integrity === undefined) throw new Error(`the lockfile pins no ${pkg}`);
  // One character of the digest changed: still a well-formed sha512, of other bytes.
  const altered = entry.integrity.replace(/^sha512-(.)/, (_, c: string) => `sha512-${c === 'A' ? 'B' : 'A'}`);
  await writeFile(join(dir, 'cli-lock.json'), JSON.stringify({ ...locked, packages: { ...locked.packages, [`node_modules/${pkg}`]: { ...entry, integrity: altered } } }, null, 2));
  return dir;
}

===== packages/drivers/codex/image/check-install.js =====
// Run in the image build, after `npm ci`, and fails the build unless every
// package the lockfile pins for this image's platform was installed as locked
// (R53).
//
// `npm ci` checks each tarball against the lockfile's integrity, but a CLI's
// platform packages are optional dependencies, and npm skips an optional
// package whose tarball fails the check rather than failing the install. A
// probe build with one platform package's hash altered warned "seems to be
// corrupted" and succeeded, and the CLI then ran from a sibling package
// (D-R53-02). So the build does not trust npm's exit code alone: a package
// the lockfile names for this platform that is not installed at its locked
// version and integrity is a build failure that names the package.
//
// usage: node check-install.js <directory holding package-lock.json and node_modules>
/* global require, process -- run by node during the image build, never imported */
/* eslint-disable @typescript-eslint/no-require-imports -- a CommonJS script: the image runs it with plain node, before any package exists */
'use strict';

const { readFileSync } = require('node:fs');
const { join } = require('node:path');

const dir = process.argv[2];
if (dir === undefined) {
  process.stderr.write('usage: node check-install.js <dir>\n');
  process.exit(2);
}

const read = (path) => JSON.parse(readFileSync(path, 'utf8'));
const locked = read(join(dir, 'package-lock.json')).packages;
// npm's record of what it installed: written by `npm ci`, one entry per package on disk.
const installed = read(join(dir, 'node_modules', '.package-lock.json')).packages;

const libc = process.report.getReport().header.glibcVersionRuntime === undefined ? 'musl' : 'glibc';

// npm's platform fields: a list of allowed values, where `!x` excludes one.
function allows(list, value) {
  if (list === undefined) return true;
  const values = Array.isArray(list) ? list : [list];
  const allowed = values.filter((v) => !v.startsWith('!'));
  return (allowed.length === 0 || allowed.includes(value)) && !values.includes(`!${value}`);
}

const problems = [];
for (const [path, entry] of Object.entries(locked)) {
  if (path === '') continue;
  const forThisPlatform = allows(entry.os, process.platform) && allows(entry.cpu, process.arch) && allows(entry.libc, libc);
  const required = entry.optional !== true || forThisPlatform;
  const got = installed[path];
  if (got === undefined) {
    if (required) problems.push(`${path}@${entry.version} is pinned for ${process.platform}-${process.arch} and was not installed`);
    continue;
  }
  if (got.version !== entry.version || got.integrity !== entry.integrity) {
    problems.push(`${path} was installed as ${got.version} ${got.integrity}, not as locked, ${entry.version} ${entry.integrity}`);
    continue;
  }
  // The package on disk, not only npm's account of it.
  let onDisk;
  try {
    onDisk = read(join(dir, path, 'package.json')).version;
  } catch {
    onDisk = undefined;
  }
  if (onDisk !== entry.version) problems.push(`${path} on disk is ${String(onDisk)}, not ${entry.version}`);
}
for (const path of Object.keys(installed)) {
  if (path !== '' && locked[path] === undefined) problems.push(`${path} was installed and is not in the lockfile`);
}

if (problems.length > 0) {
  process.stderr.write(`check-install: the install does not match the lockfile, so the image is not built:\n${problems.map((p) => `  ${p}`).join('\n')}\n`);
  process.exit(1);
}
process.stdout.write(`check-install: ${String(Object.keys(locked).length - 1)} locked packages, every one for ${process.platform}-${process.arch} installed as locked\n`);

/**
 * An image's content ID, read from the container engine (A-R53-01).
 *
 * A tag or a repository digest is a name, and the engine can be made to
 * answer a name with other bytes: a tag is moved by `docker tag`, and a
 * digest names a manifest that the engine resolves to an image it holds. The
 * content ID is the image itself. `docker run <id>` starts exactly that image
 * or refuses ("No such image"), so a sandbox provisioned from an ID runs the
 * bytes the ID names, whatever happens to the tag afterwards. That is what
 * the evidence records as `harnessImage`, and what the line provisions from.
 */
import { mkdir, mkdtemp, readFile, rm, stat, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { dockerCli } from './docker.js';
import { refuse } from './refusal.js';

/** A content ID as the engine prints it: `sha256:` and 64 hex digits. */
export const CONTENT_ID = /^sha256:[0-9a-f]{64}$/;

export interface ImageIdOptions {
  /** The Docker executable. Defaults to `docker` on PATH. */
  readonly executable?: string;
  /**
   * Pull `ref` when the engine does not hold it. Allowed only for a reference
   * pinned by digest (`name@sha256:…`): a pull by digest fetches the one
   * manifest the digest names, where a pull by tag fetches whatever the tag
   * names that day. Off by default: nothing is pulled unless asked.
   */
  readonly pull?: boolean;
}

/** A reference pinned by digest. */
const BY_DIGEST = /@sha256:[0-9a-f]{64}$/;

async function inspectId(executable: string, ref: string): Promise<{ readonly exitCode: number; readonly stdout: string; readonly stderr: string }> {
  return dockerCli(executable, ['image', 'inspect', '--format', '{{.Id}}', ref], { timeoutMs: 60_000 }).catch((error: unknown) => {
    refuse('image', `the Docker daemon could not be reached to read the content ID of ${ref}: ${String(error)}`);
  });
}

/**
 * The content ID of the image `ref` names on this engine, or a refusal: the
 * engine could not be reached, holds no such image, or answered with
 * something that is not a content ID. Nothing is pulled unless `pull` is set
 * and `ref` is pinned by digest.
 */
export async function imageId(ref: string, options: ImageIdOptions = {}): Promise<string> {
  const executable = options.executable ?? 'docker';
  if (ref.trim() === '') refuse('image', 'no image was named, so there is no content ID to read');
  if (options.pull === true && !BY_DIGEST.test(ref)) refuse('image', `${ref} is not pinned by digest, so it is not pulled: a tag names whatever it names the day it is pulled`);
  let read = await inspectId(executable, ref);
  if (read.exitCode !== 0 && options.pull === true) {
    const pulled = await dockerCli(executable, ['pull', '--quiet', ref], { timeoutMs: 600_000 }).catch((error: unknown) => {
      refuse('image', `pulling ${ref} did not finish: ${String(error)}`);
    });
    if (pulled.exitCode !== 0) refuse('image', `pulling ${ref} failed with exit code ${String(pulled.exitCode)}: ${pulled.stderr.trim()}`);
    read = await inspectId(executable, ref);
  }
  if (read.exitCode !== 0) refuse('image', `the engine holds no image ${ref}, so it has no content ID: ${read.stderr.trim()}`);
  const id = read.stdout.trim();
  if (!CONTENT_ID.test(id)) refuse('image', `the engine named ${ref}'s content ID as ${JSON.stringify(id)}, which is not sha256: and 64 hex digits`);
  return id;
}

/** The one registry a harness lockfile may resolve from. */
export const NPM_REGISTRY = 'https://registry.npmjs.org/';

const SHA512 = /^sha512-[A-Za-z0-9+/]{86}==$/;

/** The CLI a harness lockfile pins: its package name and exact version. */
export interface LockedCli {
  readonly name: string;
  readonly version: string;
}

function isObject(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value);
}

/**
 * Why a harness image's manifest and lockfile do not pin `cli` by content,
 * one line per problem, or none (R53). The image installs from the lockfile
 * with `npm ci`, which checks each tarball against the lockfile's integrity,
 * so an entry with no `sha512` integrity, or one resolved from anywhere but
 * the registry, would install whatever it is served. Both are refused before
 * a build starts, as is a lockfile whose CLI is not the version the driver
 * reports: the evidence would name one version and the image hold another.
 */
export function harnessLockProblems(manifest: unknown, lock: unknown, cli: LockedCli): string[] {
  const problems: string[] = [];
  const wanted = JSON.stringify({ [cli.name]: cli.version });
  if (!isObject(manifest) || JSON.stringify(manifest.dependencies) !== wanted) {
    problems.push(`package.json does not depend on ${cli.name} at exactly ${cli.version} and nothing else`);
  }
  if (!isObject(lock) || lock.lockfileVersion !== 3 || !isObject(lock.packages)) {
    problems.push('package-lock.json is not a version 3 lockfile with a packages map');
    return problems;
  }
  const packages = lock.packages;
  const root = packages[''];
  if (!isObject(root) || JSON.stringify(root.dependencies) !== wanted) {
    problems.push(`package-lock.json's root does not depend on ${cli.name} at exactly ${cli.version} and nothing else`);
  }
  const top = packages[`node_modules/${cli.name}`];
  if (!isObject(top) || top.version !== cli.version) {
    problems.push(`package-lock.json locks ${cli.name} at ${isObject(top) ? String(top.version) : 'no version'}, not ${cli.version}`);
  }
  for (const [path, entry] of Object.entries(packages)) {
    if (path === '') continue;
    if (!path.startsWith('node_modules/') || !isObject(entry)) {
      problems.push(`package-lock.json entry ${JSON.stringify(path)} is not an installed package`);
      continue;
    }
    if (entry.link === true) problems.push(`${path} is a link, which installs a directory rather than a tarball`);
    if (typeof entry.resolved !== 'string' || !entry.resolved.startsWith(NPM_REGISTRY)) {
      problems.push(`${path} resolves from ${JSON.stringify(entry.resolved)}, not from ${NPM_REGISTRY}`);
    }
    if (typeof entry.integrity !== 'string' || !SHA512.test(entry.integrity)) {
      problems.push(`${path} carries no sha512 integrity, so its tarball would install unchecked`);
    }
  }
  return problems;
}

export interface RecordedImageOptions {
  /** The tag the build is given, derived by the caller from every input of the build. */
  readonly tag: string;
  /** The build context. */
  readonly context: string;
  readonly buildArgs: Readonly<Record<string, string>>;
  /**
   * Where this host records the content ID of every image it built, one
   * directory per tag. It belongs to the host: no sandbox mounts it, and a
   * replaced image cannot write it.
   */
  readonly records: string;
  readonly executable?: string;
  readonly timeoutMs?: number;
}

/** A tag as a directory name: `:` and `/` are not portable in one. */
function recordDirectory(records: string, tag: string): string {
  return join(records, tag.replace(/[^A-Za-z0-9._-]/g, '_'));
}

async function recorded(records: string, tag: string, id: string): Promise<boolean> {
  return (await stat(join(recordDirectory(records, tag), id.slice('sha256:'.length))).catch(() => null))?.isFile() === true;
}

/**
 * The content ID of the image under `tag`, built here if the engine holds no
 * such tag, or a refusal (R53).
 *
 * A tag the engine already holds is accepted only when its content ID is one
 * this host recorded building under that tag. Anything else is a replaced
 * image, a finding and not a cache miss, so it is refused and never rebuilt
 * over. A build records the ID `--iidfile` names, the image that build
 * produced, before it is returned. The caller provisions from the ID, so a
 * tag moved afterwards changes nothing that runs.
 */
export async function recordedImage(options: RecordedImageOptions): Promise<string> {
  const executable = options.executable ?? 'docker';
  const { tag, records } = options;
  const present = await dockerCli(executable, ['image', 'inspect', '--format', '{{.Id}}', tag], { timeoutMs: 60_000 }).catch((error: unknown) => {
    refuse('image', `the Docker daemon could not be reached to look for ${tag}: ${String(error)}`);
  });
  if (present.exitCode === 0) {
    const id = present.stdout.trim();
    if (!CONTENT_ID.test(id)) refuse('image', `the engine named ${tag}'s content ID as ${JSON.stringify(id)}, which is not sha256: and 64 hex digits`);
    if (await recorded(records, tag, id)) return id;
    refuse(
      'image',
      `the engine holds ${tag} as ${id}, which this host has no record of building under that tag (${recordDirectory(records, tag)}). ` +
        'A replaced image is refused, never rebuilt over; remove it with `docker image rm ' + tag + '` and the next start builds and records it.',
    );
  }

  const scratch = await mkdtemp(join(tmpdir(), 'harness-image-'));
  try {
    const iidfile = join(scratch, 'iid');
    const args = ['build', '--iidfile', iidfile];
    for (const [name, value] of Object.entries(options.buildArgs)) args.push('--build-arg', `${name}=${value}`);
    args.push('--tag', tag, options.context);
    const built = await dockerCli(executable, args, { timeoutMs: options.timeoutMs ?? 600_000 }).catch((error: unknown) => {
      refuse('image', `building ${tag} did not finish: ${String(error)}`);
    });
    if (built.exitCode !== 0) {
      refuse('image', `building ${tag} failed with exit code ${String(built.exitCode)}: ${built.stderr.trim()}`);
    }
    const id = (await readFile(iidfile, 'utf8').catch(() => '')).trim();
    if (!CONTENT_ID.test(id)) refuse('image', `building ${tag} reported the content ID ${JSON.stringify(id)}, which is not sha256: and 64 hex digits`);
    const directory = recordDirectory(records, tag);
    await mkdir(directory, { recursive: true });
    await writeFile(join(directory, id.slice('sha256:'.length)), `${JSON.stringify({ tag, id, builtAt: new Date().toISOString() })}\n`);
    return id;
  } finally {
    await rm(scratch, { recursive: true, force: true });
  }
}

     const bytes = new TextEncoder().encode(JSON.stringify(r));
     const hash = sha256(bytes);
     if (!this.observations.has(hash)) this.observations.set(hash, bytes);
     return Promise.resolve(hash);
   }

     const out = [...this.observations.entries()]
       .map(([hash, bytes]) => ({ record: JSON.parse(new TextDecoder().decode(bytes)) as ObservationRecord, sha256: hash }))

     return Promise.resolve(out.sort((a, b) => a.record.recordedAt.localeCompare(b.record.recordedAt) || a.sha256.localeCompare(b.sha256)));
   }

     const out = [...this.nightly.entries()].map(([hash, bytes]) => ({ record: { review: null, observation: null, ...(JSON.parse(new TextDecoder().decode(bytes)) as object) } as NightlyRecord, sha256: hash }));

   }

       const [runId = '', kind = '', hash = ''] = key.split('/');
       yield { path: `runs/${runId}/objects/${kind}/${hash}.json`, runId: runId as RunId, named: 'content', bytes };

       yield { path: runId === null ? `observations/${hash}.json` : `runs/${runId}/observations/${hash}.json`, runId, named: 'content', bytes };
     }
   }

         const [hour = '', bucket = ''] = key.split('\0');
         return { bucket, hour, counts: { ...counts } };
       }),
     );
   }
   listRuns(): Promise<readonly RunId[]> {
     return Promise.resolve([...this.runs].sort());
   }
 
   readRunState(runId: RunId): Promise<RunState> {
     const state = this.states.get(runId);
     if (state === undefined) return Promise.reject(Object.assign(new Error(`StubVault: no run state for ${runId}`), { code: 'no-run-state' as const, runId }) satisfies NoRunState);
     // As the filesystem Vault reads a state committed before R19: no drafts, and grants that name none;
     // and before R12: no station entries (A-R12-02).
     const read = structuredClone(state) as Omit<RunState, 'drafts' | 'approvals' | 'stations' | 'narrowed'> & { drafts?: RunState['drafts']; stations?: RunState['stations']; narrowed?: RunState['narrowed']; approvals: ReadonlyArray<Omit<RunState['approvals'][number], 'draft'> & { draft?: RunState['approvals'][number]['draft'] }> };
     // Only an absent history is a legacy one; a present one that is not a list is refused, as the filesystem Vault refuses it (codex-7).
     if (read.stations !== undefined && !Array.isArray(read.stations)) {
       return Promise.reject(new Error(`StubVault: run ${runId} holds station entries that are not a list`));
     }
     return Promise.resolve({ ...read, reviews: read.reviews.map((seat) => seatBeforeR9(seat) as RunState['reviews'][number]), drafts: read.drafts ?? {}, stations: read.stations ?? [], narrowed: read.narrowed ?? null, approvals: read.approvals.map((g) => ({ ...g, draft: g.draft ?? null })) });
   }
 
   /**
    * `ifVersion` is authoritative and `s.version` is ignored; the contract
    * leaves which of the two wins to P1 (docs/decisions.md, D-S1).
    */
   commitRunState(s: RunState, ifVersion: string): Promise<RunState> {
     const current = this.states.get(s.runId)?.version ?? '0';
     if (ifVersion !== current) {
       return Promise.reject(new Error(`StubVault: run ${s.runId} is at version ${current}, not ${ifVersion}; nothing stored`));
     }
     const stored = structuredClone({ ...s, version: String(Number(current) + 1) });
     this.states.set(s.runId, stored);
     this.runs.add(s.runId);
     return Promise.resolve(structuredClone(stored));
   }
 
   private store(
     runId: RunId,
     kind: 'evidence' | 'violation' | 'admission' | 'task-result' | 'usage' | 'decision' | 'integration' | 'base-run' | 'intent' | 'rubric' | 'draft' | 'critic-result' | 'draft-lock',
     record: EvidenceBundle | IntegrityViolation | AdmissionRecord | TaskResult | UsageRecord | EnforcementDecision | IntegrationRecord | BaseRunRecord
       | IntentRecord | RubricRecord | DraftRecord | CriticRecord | DraftLockRecord,
   ): VaultRef {
     const bytes = new TextEncoder().encode(JSON.stringify(record));
     const ref: VaultRef = { runId, kind, hash: sha256(bytes) };
     this.blobs.set(refKey(ref), bytes);
     this.runs.add(runId);
     return ref;
   }
 
   /** SHA-256 of the file's bytes under root, or undefined when there is no such file. */
   private async hashFile(path: string): Promise<string | undefined> {
     try {
       return sha256(await readFile(resolve(this.root, path)));
     } catch (error) {
       if (isMissingFile(error)) return undefined;
       throw error;
     }
   }
 }
