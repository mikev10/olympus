The check results alone decide whether the task passes. Until this change, the builder could not run the tests itself. This change installs the runtime's dependency install into the builder's own copy too (`installForBuild` in packages/api/src/line.ts), and grants the shipped default builder role the `Bash` tool with no network egress (packages/api/setup/policy.yaml).
