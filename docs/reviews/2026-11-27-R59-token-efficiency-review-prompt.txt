The runtime carries a piece of work through stations, and at each one it calls
a model through a driver inside a sandbox. A relay beside the sandbox counts
the tokens and dollars of every call, and the runtime stores that count as a
usage record. This change adds three figures to the per-run report, each
derived from those records: per task, the tokens read against the tokens
written; the run's cost per merged change; and the tasks whose last call
reached a bound of its budget. It also makes the benchmark's paid tier record
tokens per task for each benchmark item, and fail a run whose tokens per driver
call grow past a margin over a result committed earlier. Which results are held
this way, and by what margin, is a list in the source, and that list is empty
in this change.

It must hold against a capable, motivated party trying to make a run look
efficient, or a token regression look like no regression, without the tokens
having been saved. Assume no deceptive intent — only that the easiest path
gets taken.
