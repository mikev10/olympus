A second vendor harness: `@olympus-ai/driver-codex` runs the Codex CLI (0.166.0) inside the Olympus sandbox, through the relay's Responses meter, with the family `openai` stated rather than derived (R26). Before every task it reads the request the session would send from an endpoint on the sandbox's loopback, and refuses a session whose tools differ from the grant, whose model differs from the one resolved, or whose credential is not the placeholder. Every workspace instruction source is off. The registry names its invariant, claim, and workspace-instruction assertions, and CI runs its paid suite under `run-driver` with `OPENAI_API_KEY`.

"@olympus-ai/sandbox": minor

The relay meters OpenAI's Responses API (A-R26-01). `RelayDialect` gains `openai-responses`: a `POST` to a granted path ending `/responses` is metered, its usage read from the body or from a stream's `response.completed` event, cached input counted as cache reads. `ModelPrice` gains `maxOutputTokens`, which every model under that dialect must name, and which an unreadable answer is charged as output. The registry asserts the budget and the fail-closed rules under the new dialect.

===== packages/drivers/codex/src/capture.ts =====
/**
 * The inspection (D-R26-02): what the session would send, read before the
 * task runs.
 *
 * The pinned CLI never prints the tools its session holds, so the driver asks
 * the one party that sees them: the endpoint. Before every task it runs the
 * same invocation once against this endpoint, started on the sandbox's own
 * loopback inside the same exec. The endpoint records every request it is
 * sent and answers a `POST .../responses` with a completed response that has
 * no output and no usage, so the CLI ends its turn at once, no model is
 * called, and no token is spent. Anything else is answered 404 and recorded,
 * so a CLI that reached for a second endpoint is seen doing it.
 *
 * What it captured is printed between two marker lines, after the CLI has
 * exited and the endpoint has been stopped, and the driver reads only what is
 * between them. The marker carries a fresh nonce per inspection, so nothing
 * the CLI printed can forge the block.
 */

/** The variable the endpoint's source travels in: never an argument, never a file the task can write first. */
export const CAPTURE_SOURCE_VARIABLE = 'DRIVER_CAPTURE_SOURCE';

/** The variable the marker nonce travels in. */
export const CAPTURE_NONCE_VARIABLE = 'DRIVER_CAPTURE_NONCE';

/**
 * The endpoint. `node --eval "$DRIVER_CAPTURE_SOURCE" <dir>`: it listens on an
 * ephemeral loopback port, writes the port to `<dir>/port` once listening, and
 * rewrites `<dir>/requests.json` after every request it receives.
 */
export const CAPTURE_SOURCE = `'use strict';
const http = require('node:http');
const fs = require('node:fs');
const path = require('node:path');
const dir = process.argv[1];
const seen = [];
const server = http.createServer(function (req, res) {
  const parts = [];
  let size = 0;
  req.on('data', function (c) { size += c.length; if (size <= 16 << 20) parts.push(c); });
  req.on('end', function () {
    const url = String(req.url || '');
    seen.push({ method: req.method, url: url, authorization: req.headers.authorization === undefined ? null : String(req.headers.authorization),
      body: size <= 16 << 20 ? Buffer.concat(parts).toString('utf8') : null });
    fs.writeFileSync(path.join(dir, 'requests.json'), JSON.stringify(seen));
    if (req.method !== 'POST' || !/\\/responses$/.test(url.split('?')[0])) { res.writeHead(404); res.end(); return; }
    res.writeHead(200, { 'content-type': 'text/event-stream' });
    const id = 'inspection';
    res.write('event: response.created\\ndata: ' + JSON.stringify({ type: 'response.created', response: { id: id, status: 'in_progress', output: [], usage: null } }) + '\\n\\n');
    res.end('event: response.completed\\ndata: ' + JSON.stringify({ type: 'response.completed', response: { id: id, status: 'completed', output: [],
      usage: { input_tokens: 0, input_tokens_details: { cached_tokens: 0 }, output_tokens: 0, total_tokens: 0 } } }) + '\\n\\n');
  });
});
server.listen(0, '127.0.0.1', function () { fs.writeFileSync(path.join(dir, 'port'), String(server.address().port)); });
`;

/** One request the endpoint recorded. */
export interface CapturedRequest {
  readonly method: string;
  readonly url: string;
  readonly authorization: string | null;
  readonly body: string | null;
}

/** What one inspection read, or why there is nothing to read. */
export type Captured = { readonly requests: readonly CapturedRequest[] } | { readonly missing: string };

export function markers(nonce: string): { readonly begin: string; readonly end: string } {
  return { begin: `driver-capture-begin-${nonce}`, end: `driver-capture-end-${nonce}` };
}

/** The block between the markers in `stdout`, parsed, or why it could not be. */
export function capturedFrom(stdout: string, nonce: string): Captured {
  const { begin, end } = markers(nonce);
  const lines = stdout.split(/\r?\n/u);
  const from = lines.indexOf(begin);
  const to = lines.indexOf(end);
  if (from === -1 || to === -1 || to <= from) return { missing: 'the inspection printed no capture block' };
  const block = lines.slice(from + 1, to).join('\n').trim();
  if (block === '') return { missing: 'the capture endpoint recorded no request' };
  let parsed: unknown;
  try {
    parsed = JSON.parse(block);
  } catch {
    return { missing: 'the capture block is not JSON' };
  }
  if (!Array.isArray(parsed)) return { missing: 'the capture block is not a list of requests' };
  const requests: CapturedRequest[] = [];
  for (const entry of parsed as unknown[]) {
    if (typeof entry !== 'object' || entry === null) return { missing: 'the capture block holds an entry that is not a request' };
    const r = entry as Record<string, unknown>;
    if (typeof r.method !== 'string' || typeof r.url !== 'string') return { missing: 'the capture block holds a request with no method or URL' };
    requests.push({
      method: r.method,
      url: r.url,
      authorization: typeof r.authorization === 'string' ? r.authorization : null,
      body: typeof r.body === 'string' ? r.body : null,
    });
  }
  return { requests };
}

/** The variable the CLI reads its key from (`model_providers.<id>.env_key`). It carries `KEY_PLACEHOLDER`, never a credential. */
export const KEY_VARIABLE = 'OPENAI_API_KEY';

/** What the CLI sends where a key would go. The relay drops it and writes the credential it holds (D-P12-03). */
export const KEY_PLACEHOLDER = 'relay-held-credential-placeholder';

/** The name of the credential the relay is given: `LocalDockerProvider.create({ credentials: { [MODEL_CREDENTIAL]: key } })`. */
export const MODEL_CREDENTIAL = 'openai';

/** The variable the provider gives the relay's address in. The CLI is pointed at it on the argv, never through its own defaults. */
export const RELAY_URL_VARIABLE = 'MODEL_RELAY_URL';

/** The date the prices in `MODEL_METER` were read from OpenAI's published list. */
export const PRICES_AS_OF = '2026-10-31';

/**
 * A model's price at its ceiling (D-R26-06): OpenAI bills a prompt over 272K
 * input tokens at twice the input rate and one and a half times the output
 * rate, and the meter cannot see a prompt's length before it prices one, so
 * every call is priced as though it were that long. The dollar figure is then
 * high, by those factors, and never low. The Responses API reports no cache
 * writes, so their prices are never charged; they are set to the input rate's
 * ceiling only so the table has no zero a reader could take for free.
 */
function price(input: number, cached: number, output: number): ModelPrice {
  const longInput = input * 2;
  return {
    inputPerMTok: longInput,
    outputPerMTok: output * 1.5,
    cacheReadPerMTok: cached * 2,
    cacheWritePerMTok: longInput,
    cacheWrite1hPerMTok: longInput,
    maxOutputTokens: 128_000,
  };
}

/**
 * How the relay reads a call of this driver and what each model costs
 * (A-R26-01). List prices per million tokens, as of `PRICES_AS_OF`, before
 * the ceiling factors: input, cached input, output. A model not here is
 * refused by the relay before its request is sent.
 */
export const MODEL_METER: Readonly<RelayMeter> = Object.freeze({
  dialect: 'openai-responses',
  prices: Object.freeze({
    'gpt-5.6-luna': price(0.2, 0.02, 1.2),
    'gpt-5.6-terra': price(2, 0.2, 12),
    'gpt-5.6-sol': price(4, 0.4, 20),
  }),
});

/**
 * The relay a sandbox this driver runs in must be provisioned with: the API
 * origin, the one path the CLI calls, the header and scheme the API reads a
 * key in, the variable the relay's address is given in, and the meter. The
 * budget is the task's, added by whoever provisions the sandbox (D-P13-01).
 */
export const MODEL_RELAY: Readonly<Omit<RelaySpec, 'budget'>> = Object.freeze({
  upstream: 'https://api.openai.com',
  paths: ['/v1/responses'],
  header: 'authorization',
  scheme: 'bearer',
  credential: MODEL_CREDENTIAL,
  urlVariable: RELAY_URL_VARIABLE,
  meter: MODEL_METER,
});

/**
 * I6: the family is a value this driver states, here, once. It is not derived
 * from `id`, the provider, the tier, or a model name, and nothing the CLI or
 * the API reports can change it.
 */
export const FAMILY = 'openai' as ModelFamily;

/** The most tasks this driver runs at once, each on its own sandbox (A-R4-04). */
export const PARALLELISM = 4;

/** Tier to model, by the exact name the relay prices (D-R26-05). */
export const TIER_MODELS: Readonly<Record<ModelTier, string>> = Object.freeze({
  fast: 'gpt-5.6-luna',
  standard: 'gpt-5.6-terra',
  deep: 'gpt-5.6-sol',
});

/** The catalogs the image writes, owned by root (D-R26-04). */
export const CATALOG_WITH_PATCH = '/opt/codex/catalog-patch.json';
export const CATALOG_WITHOUT_PATCH = '/opt/codex/catalog-no-patch.json';

/** Where each invocation makes its own home (D-R26-09). */
export const HOMES_DIR = '/codex-homes';

/** The model provider the argv defines. Its name is the driver's, so no provider the CLI ships is used by accident. */
const PROVIDER_ID = 'model-relay';

/** How long the inspection may take. It calls no model, so this bounds a CLI that failed to start. */
const INSPECT_TIMEOUT_SECONDS = 90;

/** A working directory the argv can name inside a TOML key without quoting surprises. */
const SAFE_DIR = /^\/[A-Za-z0-9._/-]*$/u;

export interface CodexDriverOptions {
  /** The provider that provisioned the handle in `TaskRequest.sandbox`. Not optional: there is no host fallback (I1). */
  readonly provider: SandboxProvider;
  /** The working directory inside the sandbox. Defaults to the workspace mount's usual target. */
  readonly workdir?: string;
  /** Overrides the tier-to-model map. Every model must be in `MODEL_METER`, or the relay refuses its calls. */
  readonly models?: Readonly<Record<ModelTier, string>>;
}

/**
 * What the inspection read from the session's one request. Kept per task so a
 * caller and the suite can see what the session was configured with, rather
 * than inferring it from what the model said.
 */
export interface Inspection {
  readonly tools: readonly string[];
  readonly model: string;
  readonly authorization: string | null;
  /** The request body the session would have sent, verbatim. */
  readonly body: string;
}

/** A UTF-16 code unit that is half of a pair with no other half. */
// No u flag: under it a lone surrogate cannot be matched, which is the one thing this pattern is for.
const LONE_SURROGATE = /[\uD800-\uDBFF](?![\uDC00-\uDFFF])|(?<![\uD800-\uDBFF])[\uDC00-\uDFFF]/;

/** A TOML basic string. JSON's escapes are TOML's, save DEL, which TOML forbids raw; a value that is not well-formed UTF-16 is refused. */
export function tomlString(value: string): string {
  if (LONE_SURROGATE.test(value)) refuse('invocation', 'a value for the CLI configuration holds an unpaired surrogate, which TOML cannot carry');
  return JSON.stringify(value).replaceAll('\u007f', '\\u007f');
}

export class CodexDriver implements Driver {
  readonly id = 'codex';
  readonly contractVersion = DRIVER_CONTRACT_VERSION;

  readonly #provider: SandboxProvider;
  readonly #workdir: string;
  readonly #models: Readonly<Record<ModelTier, string>>;
  readonly #inFlight = new Map<SandboxHandle, Promise<unknown>>();
  #running = 0;
  readonly #waiting: Array<() => void> = [];
  readonly #handlers = new Map<DriverEvent['kind'], Array<(e: DriverEvent) => void>>();
  readonly #inspections = new Map<TaskId, Inspection>();

  constructor(options: CodexDriverOptions) {
    // eslint-disable-next-line @typescript-eslint/no-unnecessary-condition -- the type requires a provider, but a missing one here means running the model on the host (I1). A caller from untyped code is refused, not trusted.
    if (options.provider === undefined || options.provider === null) {
      refuse('provider', 'CodexDriver needs the SandboxProvider that provisioned the handle; there is no host fallback (I1)');
    }
    const workdir = options.workdir ?? '/workspace';
    if (!SAFE_DIR.test(workdir)) {
      refuse('capability', `the working directory ${JSON.stringify(workdir)} is not a plain absolute path; it is named in the CLI's configuration, which is TOML`);
    }
    const models = options.models ?? TIER_MODELS;
    for (const [tier, model] of Object.entries(models)) {
      if (!Object.hasOwn(MODEL_METER.prices, model)) {
        refuse('capability', `tier '${tier}' maps to ${JSON.stringify(model)}, which MODEL_METER does not price, so the relay would refuse every call`);
      }
    }
    this.#provider = options.provider;
    this.#workdir = workdir;
    this.#models = models;
  }

  provenanceId(): string {
    return `${this.id}@${CLI_VERSION}`;
  }

  /**
   * Each value is asserted against the real CLI under `driver.<key>.codex`
   * (I8, D-R26-07). The `false` ones have no method behind them: a method
   * present beside a capability declared false is the direction the
   * conformance assertion refuses.
   */
  capabilities(): DriverCapabilities {
    return {
      subagents: false,
      hooks: false,
      mcp: false,
      parallelism: PARALLELISM,
      computerUse: false,
      steering: false,
      stablePrefixCaching: false,
    };
  }

  declaredTools(): readonly string[] {
    return DECLARED_TOOLS_VIEW;
  }

  relayRequest(): Omit<RelaySpec, 'budget'> {
    return { ...MODEL_RELAY, paths: [...MODEL_RELAY.paths] };
  }

  /** I6: `family` is `FAMILY`, assigned. Nothing here reads the tier, the model, or `this.id` to produce it. */
  resolveModel(tier: ModelTier): ModelIdentity {
    const model = this.#models[tier];
    // eslint-disable-next-line @typescript-eslint/no-unnecessary-condition -- a tier from parsed configuration can be outside the union, and an undefined model would reach the argv as 'undefined'.
    if (model === undefined) refuse('capability', `no model is mapped to tier '${tier}'`);
    return { provider: 'openai', family: FAMILY, model, version: CLI_VERSION };
  }

  runTask(req: TaskRequest): Promise<TaskResult> {
    return this.#serialized(req.sandbox, () => this.#runTask(req));
  }

  /** Forgets a task's inspection. The container is the run's, so nothing here destroys it. */
  cancel(taskId: TaskId): Promise<void> {
    this.#inspections.delete(taskId);
    return Promise.resolve();
  }

  /** `hooks` is false: there is no artifact format this driver installs, so it refuses and writes nothing. */
  emitArtifacts(roles: CompiledRole[], targetDir: string): Promise<void> {
    return Promise.reject(
      new DriverRefusal(
        'capability',
        `emitArtifacts was asked for ${String(roles.length)} role(s) under ${targetDir}, but this driver declares hooks false and installs no artifacts; ` +
          'a role reaches the session on the argv alone (D-R26-08)',
      ),
    );
  }

  on(kind: DriverEvent['kind'], handler: (e: DriverEvent) => void): void {
    const existing = this.#handlers.get(kind);
    if (existing === undefined) this.#handlers.set(kind, [handler]);
    else existing.push(handler);
  }

  /** What the inspection read for a task, once one has run. */
  inspectionFor(taskId: TaskId): Inspection | undefined {
    return this.#inspections.get(taskId);
  }

  /**
   * Runs the inspection alone and returns what it read, refusing as a task
   * would. No model is called. The suite uses it to read the request a
   * session would send without paying for one.
   */
  inspect(req: TaskRequest): Promise<Inspection> {
    return this.#serialized(req.sandbox, async () => {
      const groups = this.#groupsOrRefuse(req);
      const identity = this.resolveModel(req.tier);
      return this.#inspect(req, identity, groups);
    });
  }

  async #serialized<T>(handle: SandboxHandle, body: () => Promise<T>): Promise<T> {
    for (let held = this.#inFlight.get(handle); held !== undefined; held = this.#inFlight.get(handle)) {
      await held.catch(() => undefined);
    }
    const running = this.#bounded(body);
    this.#inFlight.set(handle, running);
    try {
      return await running;
    } finally {
      if (this.#inFlight.get(handle) === running) this.#inFlight.delete(handle);
    }
  }

  async #bounded<T>(body: () => Promise<T>): Promise<T> {
    if (this.#running >= PARALLELISM) await new Promise<void>((admit) => this.#waiting.push(admit));
    else this.#running += 1;
    try {
      return await body();
    } finally {
      const next = this.#waiting.shift();
      if (next === undefined) this.#running -= 1;
      else next();
    }
  }

  async #runTask(req: TaskRequest): Promise<TaskResult> {
    const groups = this.#groupsOrRefuse(req);
    const identity = this.resolveModel(req.tier);
    await this.#inspect(req, identity, groups);

    const exec = await this.#provider.exec(req.sandbox, runArgv(this.#workdir, cliArgs(this.#workdir, identity.model, req, groups)), {
      env: { [KEY_VARIABLE]: KEY_PLACEHOLDER },
    });
    const parsed = parseEvents(exec.stdout);
    refuseUnusable(req, exec.exitCode, exec.stderr, parsed, identity);
    const events = eventsFrom(parsed);
    for (const event of events) this.#emit(event);
    return {
      taskId: req.taskId,
      claim: claimFrom(parsed),
      events,
      usage: usageFrom(parsed, identity.model, exec.durationMs),
      // The CLI reports no model of its own (D-R26-01); a reroute it did report was refused above.
      model: identity,
      contractVersion: this.contractVersion,
    };
  }

  /** I4: the grant is refused unless the CLI can offer exactly it. */
  #groupsOrRefuse(req: TaskRequest): readonly ToolGroup[] {
    const mcp = req.tools.filter((tool) => tool.startsWith('mcp__'));
    if (mcp.length > 0) {
      refuse('grant', `the task grants ${mcp.map((t) => `'${t}'`).join(', ')}, but this driver declares mcp false and configures no server (D-R26-07)`);
    }
    const result = groupsFor(req.tools);
    if ('refusal' in result) {
      refuse('grant', `${result.refusal}. The task was not started: a grant this driver cannot honour exactly means something other than what it says (I4).`);
    }
    return result.groups;
  }

  /** D-R26-02: the request the session would send, read from an endpoint on the sandbox's loopback, and held to the grant. */
  async #inspect(req: TaskRequest, identity: ModelIdentity, groups: readonly ToolGroup[]): Promise<Inspection> {
    const nonce = crypto.randomUUID();
    const exec = await this.#provider.exec(req.sandbox, inspectArgv(this.#workdir, nonce, cliArgs(this.#workdir, identity.model, req, groups)), {
      env: { [KEY_VARIABLE]: KEY_PLACEHOLDER, [CAPTURE_SOURCE_VARIABLE]: CAPTURE_SOURCE, [CAPTURE_NONCE_VARIABLE]: nonce, NO_PROXY: '127.0.0.1', no_proxy: '127.0.0.1' },
    });
    const captured = capturedFrom(exec.stdout, nonce);
    if ('missing' in captured) {
      refuse(
        'invocation',
        `the session for task ${req.taskId} could not be inspected: ${captured.missing} (exit code ${String(exec.exitCode)})` +
          (exec.stderr.trim() === '' ? '' : `; stderr: ${exec.stderr.trim().slice(0, 400)}`) +
          '. The task was not started: running it would offer the model tools nobody has enumerated (I4, I5).',
      );
    }
    const inspection = inspectionFrom(req, captured.requests);
    const granted = [...new Set(req.tools)].sort((a, b) => a.localeCompare(b));
    const offered = [...new Set(inspection.tools)].sort((a, b) => a.localeCompare(b));
    const ungranted = offered.filter((tool) => !granted.includes(tool));
    const missing = granted.filter((tool) => !offered.includes(tool));
    if (ungranted.length > 0 || missing.length > 0 || offered.length !== inspection.tools.length) {
      refuse(
        'grant',
        `the session for task ${req.taskId} would offer [${inspection.tools.join(', ')}] where the request granted [${granted.join(', ')}]` +
          (ungranted.length > 0 ? `; ${ungranted.join(', ')} not granted (I4)` : '') +
          (missing.length > 0 ? `; ${missing.join(', ')} granted and absent, so the grant did not take effect (I5)` : ''),
      );
    }
    if (inspection.model !== identity.model) {
      refuse('invocation', `the session for task ${req.taskId} would ask for ${JSON.stringify(inspection.model)} where the runtime resolved ${identity.model}`);
    }
    if (inspection.authorization !== `Bearer ${KEY_PLACEHOLDER}`) {
      refuse(
        'credential',
        `the session for task ${req.taskId} would authenticate with something other than the placeholder in ${KEY_VARIABLE}; ` +
          'a key the driver did not supply is one it cannot account for, and one the CLI found is a credential inside the sandbox',
      );
    }
    this.#inspections.set(req.taskId, inspection);
    return inspection;
  }

  #emit(event: DriverEvent): void {
    for (const handler of this.#handlers.get(event.kind) ?? []) handler(event);
  }
}

/** What `declaredTools()` hands out: a frozen copy, so a caller cannot widen the inventory. */
const DECLARED_TOOLS_VIEW: readonly string[] = Object.freeze([...DECLARED_TOOLS]);

/** The one request an inspection may see, read into what the driver checks. Anything else is refused. */
function inspectionFrom(req: TaskRequest, requests: readonly CapturedRequest[]): Inspection {
  const posts = requests.filter((r) => r.method === 'POST' && (r.url.split('?')[0] ?? '').endsWith('/responses'));
  const others = requests.filter((r) => !posts.includes(r));
  if (others.length > 0) {
    refuse(
      'invocation',
      `the session for task ${req.taskId} reached ${others.map((r) => `${r.method} ${r.url}`).join(', ')} beside the Responses endpoint; ` +
        'the relay grants that one path, so the task would fail for a reason that is not its own',
    );
  }
  const first = posts[0];
  if (posts.length !== 1 || first?.body == null) {
    refuse('invocation', `the session for task ${req.taskId} sent ${String(posts.length)} readable Responses request(s) during inspection, not one`);
  }
  let body: unknown;
  try {
    body = JSON.parse(first.body);
  } catch {
    refuse('invocation', `the session for task ${req.taskId} sent a Responses request whose body is not JSON`);
  }
  const fields = typeof body === 'object' && body !== null ? (body as Record<string, unknown>) : {};
  const tools = fields.tools ?? [];
  if (!Array.isArray(tools)) refuse('invocation', `the session for task ${req.taskId} sent a tools field that is not a list`);
  const names = (tools as unknown[]).map((tool) => {
    const t = typeof tool === 'object' && tool !== null ? (tool as Record<string, unknown>) : {};
    const name = typeof t.name === 'string' ? t.name : typeof t.type === 'string' ? `type:${t.type}` : undefined;
    if (name === undefined) refuse('invocation', `the session for task ${req.taskId} offers a tool with neither a name nor a type`);
    return name;
  });
  // A tool list delivered inside the input, as code mode delivers one, is a set this check cannot read (D-R26-04).
  const input = Array.isArray(fields.input) ? (fields.input as unknown[]) : [];
  if (input.some((item) => typeof item === 'object' && item !== null && (item as Record<string, unknown>).type === 'additional_tools')) {
    refuse('invocation', `the session for task ${req.taskId} carries its tools inside the input, which the driver cannot hold to the grant`);
  }
  return { tools: names, model: typeof fields.model === 'string' ? fields.model : '', authorization: first.authorization, body: first.body };
}

/**
 * The CLI's arguments after `codex exec`, the same for the inspection and the run.
 * The base URL is not here: each wrapper puts its own first, before the `--`
 * that ends the options, so the two invocations differ in that one argument.
 */
export function cliArgs(workdir: string, model: string, req: TaskRequest, groups: readonly ToolGroup[]): string[] {
  const held = new Set(groups);
  const args = [
    '--json',
    '--skip-git-repo-check',
    '--ephemeral',
    // Nothing from a home or rules file configures the session, and a fresh home holds none anyway (D-R26-09).
    '--ignore-user-config',
    '--ignore-rules',
    // The container is the sandbox, and nobody is there to approve (D-R26-11).
    '--dangerously-bypass-approvals-and-sandbox',
    '--cd', workdir,
    '--model', model,
    '-c', `model_provider=${tomlString(PROVIDER_ID)}`,
    '-c', `model_providers.${PROVIDER_ID}.name=${tomlString(PROVIDER_ID)}`,
    '-c', `model_providers.${PROVIDER_ID}.env_key=${tomlString(KEY_VARIABLE)}`,
    '-c', `model_providers.${PROVIDER_ID}.wire_api="responses"`,
    '-c', `model_providers.${PROVIDER_ID}.supports_websockets=false`,
    '-c', `model_providers.${PROVIDER_ID}.capabilities.remote_compaction="unsupported"`,
    // The catalog decides apply_patch, and the rest of its overrides hold for every task (D-R26-04).
    '-c', `model_catalog_json=${tomlString(groups.some((g) => g.lever.kind === 'catalog') ? CATALOG_WITH_PATCH : CATALOG_WITHOUT_PATCH)}`,
    // Workspace instructions off, every source of them (D-A-DD-03).
    '-c', 'project_doc_max_bytes=0',
    '-c', `projects.${tomlString(workdir)}.trust_level="untrusted"`,
    '-c', 'skills.include_instructions=false',
    '-c', 'skills.bundled.enabled=false',
    '--disable', 'plugins',
    '--disable', 'hooks',
    '--disable', 'apps',
    '--disable', 'memories',
    // With the catalog's multi_agent_version null, this leaves no multi-agent tool; either alone does not (D-R26-03).
    '--disable', 'multi_agent',
    // Never offered (D-R26-03).
    '-c', 'web_search="disabled"',
    '-c', 'tools.experimental_request_user_input.enabled=false',
    // The role and the granted context, on the argv and never in the workspace (D-R26-08).
    '-c', `developer_instructions=${tomlString(`${req.role.instructions}\n\n${req.stablePrefix}`)}`,
  ];
  for (const group of TOOL_GROUP_FEATURES) {
    args.push(held.has(group) ? '--enable' : '--disable', featureOf(group));
  }
  args.push('--', req.variableSuffix);
  return args;
}

const TOOL_GROUP_FEATURES: readonly ToolGroup[] = TOOL_GROUPS.filter((group) => group.lever.kind === 'feature');

function featureOf(group: ToolGroup): string {
  if (group.lever.kind !== 'feature') throw new Error('a catalog lever has no feature');
  return group.lever.feature;
}

/** Makes a fresh home, then runs the CLI as the process itself. `exec "$@"` keeps every argument an argv element the shell never re-reads. */
function runArgv(workdir: string, args: readonly string[]): string[] {
  const script = [
    'set -eu',
    `home="$(mktemp -d ${HOMES_DIR}/h.XXXXXX)"`,
    'export HOME="$home" CODEX_HOME="$home"',
    `cd ${shellQuote(workdir)}`,
    `exec codex exec -c "model_providers.${PROVIDER_ID}.base_url=\\"\${${RELAY_URL_VARIABLE}}/v1\\"" "$@"`,
  ].join('\n');
  return ['sh', '-c', script, 'driver', ...args];
}

/**
 * The inspection: the endpoint on loopback, the CLI pointed at it, and the
 * capture printed between markers once both have stopped. The CLI's own
 * output is discarded, so nothing it prints can stand between the markers.
 * Exported so the suite can run a control through the same capture.
 */
export function inspectArgv(workdir: string, nonce: string, args: readonly string[]): string[] {
  const { begin, end } = markers(nonce);
  const script = [
    'set -eu',
    `home="$(mktemp -d ${HOMES_DIR}/h.XXXXXX)"`,
    `cap="$(mktemp -d ${HOMES_DIR}/c.XXXXXX)"`,
    'export HOME="$home" CODEX_HOME="$home"',
    `node --eval "$${CAPTURE_SOURCE_VARIABLE}" "$cap" & server=$!`,
    'i=0; while [ ! -s "$cap/port" ] && [ "$i" -lt 100 ]; do sleep 0.1; i=$((i+1)); done',
    '[ -s "$cap/port" ] || { kill "$server" 2>/dev/null; echo "the capture endpoint did not start" >&2; exit 1; }',
    `cd ${shellQuote(workdir)}`,
    `timeout ${String(INSPECT_TIMEOUT_SECONDS)} codex exec -c "model_providers.${PROVIDER_ID}.base_url=\\"http://127.0.0.1:$(cat "$cap/port")/v1\\"" "$@" >/dev/null 2>"$cap/stderr" || true`,
    'kill "$server" 2>/dev/null || true; wait "$server" 2>/dev/null || true',
    `printf '%s\\n' ${shellQuote(begin)}`,
    'cat "$cap/requests.json" 2>/dev/null || true',
    `printf '\\n%s\\n' ${shellQuote(end)}`,
    'tail -c 400 "$cap/stderr" >&2 || true',
    'rm -rf "$home" "$cap"',
  ].join('\n');
  return ['sh', '-c', script, 'driver', ...args];
}

/** Fail closed on anything that means the task did not run as asked (I5). */
function refuseUnusable(req: TaskRequest, exitCode: number, stderr: string, parsed: ParsedEvents, identity: ModelIdentity): void {
  const tail = stderr.trim() === '' ? '' : `; stderr: ${stderr.trim().slice(-400)}`;
  if (parsed.threadId === undefined) {
    refuse('invocation', `the CLI started no session for task ${req.taskId} (exit code ${String(exitCode)})${tail}`);
  }
  if (parsed.unreadable.length > 0 || parsed.unknown.length > 0) {
    refuse(
      'invocation',
      `the CLI reported what this driver does not read for task ${req.taskId}: ` +
        [...parsed.unknown, ...parsed.unreadable.map((line) => JSON.stringify(line.slice(0, 200)))].join(', ') +
        '. An item outside the declared tools is a capability nobody granted, and an unread event is one nobody checked (I4, I5).',
    );
  }
  if (parsed.reroute !== undefined) {
    refuse('invocation', `the API rerouted task ${req.taskId} from ${identity.model} to ${parsed.reroute}; work by another model is not attributed to the one the runtime chose (I6)`);
  }
  if (parsed.failures.length > 0) {
    refuse('invocation', `task ${req.taskId} failed: ${parsed.failures.map((f) => JSON.stringify(f.slice(0, 300))).join('; ')}${tail}`);
  }
  if (parsed.usage === undefined || exitCode !== 0) {
    refuse('invocation', `the CLI ended task ${req.taskId} without completing a turn (exit code ${String(exitCode)})${tail}`);
  }
}

/** Observations of the invocation, built from what the CLI reported, never from what the model said about itself. */
export function eventsFrom(parsed: ParsedEvents): DriverEvent[] {
  const at = new Date().toISOString();
  const events: DriverEvent[] = [];
  for (const command of parsed.commands) {
    events.push({ at, kind: 'tool-call', detail: { tool: 'exec_command' } });
    events.push({ at, kind: 'command', detail: { tool: 'exec_command', command: command.command, exitCode: command.exitCode } });
  }
  for (const path of parsed.changedPaths) {
    events.push({ at, kind: 'tool-call', detail: { tool: 'apply_patch' } });
    events.push({ at, kind: 'file-write', detail: { tool: 'apply_patch', path } });
  }
  return events;
}

/** The narrative and the files the session says it changed. Both are claims (I2). */
function claimFrom(parsed: ParsedEvents): AgentClaim {
  return { narrative: parsed.messages.at(-1) ?? '', filesChanged: [...new Set(parsed.changedPaths)] };
}

/**
 * The CLI's account of the task. Its `input_tokens` include the cached ones,
 * as the API's do, so the cached part is taken out, the way the relay counts
 * it (A-R26-01). The dollars are the meter's own prices, so the figure is the
 * relay's arithmetic over the CLI's counts.
 */
function usageFrom(parsed: ParsedEvents, model: string, durationMs: number): Usage {
  const u = parsed.usage ?? { inputTokens: 0, cachedInputTokens: 0, cacheWriteTokens: 0, outputTokens: 0 };
  const cached = Math.min(u.cachedInputTokens, u.inputTokens);
  const input = u.inputTokens - cached;
  const p = MODEL_METER.prices[model];
  const costUsd = p === undefined ? 0 : (input * p.inputPerMTok + u.outputTokens * p.outputPerMTok + cached * p.cacheReadPerMTok) / 1e6;
  return { inputTokens: input, outputTokens: u.outputTokens, cacheReadTokens: cached, cacheWriteTokens: u.cacheWriteTokens, costUsd, wallClockMs: durationMs };
}

/** Single-quotes a value for `sh -c`. */
export function shellQuote(value: string): string {
  return `'${value.replaceAll("'", "'\\''")}'`;
}


===== packages/drivers/codex/src/events.ts =====
/**
 * Reads what `codex exec --json` prints: one JSON event per line.
 *
 * The event and item types are the pinned CLI's (`exec/src/exec_events.rs` at
 * `rust-v0.166.0`). The reader is closed in both directions. A line that does
 * not parse, a top-level type not in that list, and an item type this driver
 * has no reason to see are each recorded, and the driver refuses the task on
 * any of them (I5): an item the session should not be able to produce, such
 * as a web search or an MCP call, means it held a tool nobody granted, and an
 * event this reader cannot name is one whose meaning nobody checked.
 */

export interface CodexUsage {
  readonly inputTokens: number;
  readonly cachedInputTokens: number;
  readonly cacheWriteTokens: number;
  readonly outputTokens: number;
}

export interface CommandItem {
  readonly command: string;
  readonly exitCode: number | null;
}

export interface ParsedEvents {
  readonly threadId: string | undefined;
  /** The text of every completed agent message, in order. The last is the narrative. */
  readonly messages: readonly string[];
  readonly commands: readonly CommandItem[];
  /** Every path a completed file change names. A claim, never evidence (I2). */
  readonly changedPaths: readonly string[];
  /** The message of every error item, the reroute included. */
  readonly errorItems: readonly string[];
  /** A model the CLI says it was rerouted to, or `undefined`. */
  readonly reroute: string | undefined;
  /** Every turn's usage, summed. `undefined` when no turn completed. */
  readonly usage: CodexUsage | undefined;
  /** Why a turn failed, or the session errored, in order. */
  readonly failures: readonly string[];
  /** Lines that did not parse as an event object. */
  readonly unreadable: readonly string[];
  /** Event and item types this reader does not accept, as `event:<type>` or `item:<type>`. */
  readonly unknown: readonly string[];
}

const EVENT_TYPES = new Set(['thread.started', 'turn.started', 'turn.completed', 'turn.failed', 'item.started', 'item.updated', 'item.completed', 'error']);

/** The items a session of this driver can produce: no tool outside the declared set reports any other kind. */
const ITEM_TYPES = new Set(['agent_message', 'reasoning', 'command_execution', 'file_change', 'error']);

/** How the pinned CLI names a reroute in an error item (`exec/src/event_processor_with_jsonl_output.rs:496-503`). */
const REROUTE = /^model rerouted: (\S+) -> (\S+)/u;

function record(value: unknown): Record<string, unknown> | undefined {
  return typeof value === 'object' && value !== null && !Array.isArray(value) ? (value as Record<string, unknown>) : undefined;
}

function count(value: unknown): number {
  return typeof value === 'number' && Number.isFinite(value) && value >= 0 ? value : 0;
}

function text(value: unknown): string {
  return typeof value === 'string' ? value : '';
}

export function parseEvents(stdout: string): ParsedEvents {
  let threadId: string | undefined;
  const messages: string[] = [];
  const commands: CommandItem[] = [];
  const changedPaths: string[] = [];
  const errorItems: string[] = [];
  let reroute: string | undefined;
  let usage: { inputTokens: number; cachedInputTokens: number; cacheWriteTokens: number; outputTokens: number } | undefined;
  const failures: string[] = [];
  const unreadable: string[] = [];
  const unknown: string[] = [];

  for (const line of stdout.split(/\r?\n/u)) {
    if (line.trim() === '') continue;
    let parsed: unknown;
    try {
      parsed = JSON.parse(line);
    } catch {
      unreadable.push(line);
      continue;
    }
    const event = record(parsed);
    const type = event?.type;
    if (event === undefined || typeof type !== 'string') {
      unreadable.push(line);
      continue;
    }
    if (!EVENT_TYPES.has(type)) {
      unknown.push(`event:${type}`);
      continue;
    }
    if (type === 'thread.started') {
      threadId = text(event.thread_id);
    } else if (type === 'turn.completed') {
      const u = record(event.usage);
      usage ??= { inputTokens: 0, cachedInputTokens: 0, cacheWriteTokens: 0, outputTokens: 0 };
      usage.inputTokens += count(u?.input_tokens);
      usage.cachedInputTokens += count(u?.cached_input_tokens);
      usage.cacheWriteTokens += count(u?.cache_write_input_tokens);
      usage.outputTokens += count(u?.output_tokens);
    } else if (type === 'turn.failed') {
      failures.push(text(record(event.error)?.message) || 'the turn failed without a message');
    } else if (type === 'error') {
      failures.push(text(event.message) || 'the session reported an error without a message');
    } else if (type.startsWith('item.')) {
      const item = record(event.item);
      const kind = item?.type;
      if (item === undefined || typeof kind !== 'string') {
        unreadable.push(line);
        continue;
      }
      if (!ITEM_TYPES.has(kind)) {
        unknown.push(`item:${kind}`);
        continue;
      }
      // Only a completed item is counted: a started or updated one is reported again when it ends.
      if (type !== 'item.completed') continue;
      if (kind === 'agent_message') messages.push(text(item.text));
      else if (kind === 'command_execution') {
        commands.push({ command: text(item.command), exitCode: typeof item.exit_code === 'number' ? item.exit_code : null });
      } else if (kind === 'file_change') {
        const changes = Array.isArray(item.changes) ? item.changes : [];
        for (const change of changes) {
          const path = text(record(change)?.path);
          if (path !== '') changedPaths.push(path);
        }
      } else if (kind === 'error') {
        const message = text(item.message);
        errorItems.push(message);
        const rerouted = REROUTE.exec(message);
        if (rerouted !== null) reroute = rerouted[2];
      }
    }
  }
  return { threadId, messages, commands, changedPaths, errorItems, reroute, usage, failures, unreadable, unknown };
}

===== packages/drivers/codex/src/image.ts =====
/**
 * The image a task runs in.
 *
 * No published image carries the Codex CLI, so this package builds one
 * rather than pulling one. Both inputs are pinned — the base by digest, the
 * CLI by exact version — so the image is a function of two constants in this
 * file and `image/Dockerfile`, and a reviewer who builds it gets what CI
 * built. The tag carries the CLI version, so bumping the version builds a
 * different image instead of quietly replacing one under the same name.
 *
 * This is beside the image `packages/sandbox` pins for its own suite, not
 * downstream of it: that one is an alpine that has to run `sh`, this one has
 * to run a model runner, and neither should move because the other did.
 */
import { spawn } from 'node:child_process';
import { createHash } from 'node:crypto';
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';
import { refuse } from './refusal.js';

/** The base, by digest. `node:22-bookworm-slim` at the time it was pinned. */
export const BASE_IMAGE = 'node@sha256:83f487e0a63425e5b4d146fb5e5be574bcbe1b7b843d3ebafdd95eaf7767a7e5';

/** The CLI, by exact version. Never a range: a range makes the image a function of the day it was built. */
export const CLI_VERSION = '0.166.0';

/**
 * The tag the built image carries, derived from everything that decides what is
 * in it: the Dockerfile's bytes, the catalog generator's, the base digest, and the CLI version.
 *
 * A tag naming the CLI version alone does not identify the image. `ensureImage`
 * returns as soon as the daemon holds the tag, so changing the Dockerfile or
 * the base while leaving the CLI version alone left every machine that had
 * built the old one running it -- old runtime bytes under a report that hashes
 * the new source and blesses the result as current. Deriving the tag from the
 * inputs makes that impossible: different inputs are a different tag, and a
 * different tag is a build.
 */
export function imageTag(): string {
  const dockerfile = readFileSync(join(imageContext(), 'Dockerfile'));
  const catalog = readFileSync(join(imageContext(), 'catalog.js'));
  const digest = createHash('sha256')
    .update(`${BASE_IMAGE}\n${CLI_VERSION}\n`)
    .update(dockerfile)
    .update(catalog)
    .digest('hex')
    .slice(0, 16);
  return `factory-codex:${CLI_VERSION}-${digest}`;
}

/** The directory holding the Dockerfile, resolved from this module rather than from the caller's cwd. */
export function imageContext(): string {
  return join(dirname(fileURLToPath(import.meta.url)), '..', 'image');
}

interface Ran {
  readonly exitCode: number;
  readonly stderr: string;
}

function docker(executable: string, args: string[], timeoutMs: number): Promise<Ran> {
  return new Promise((resolvePromise, rejectPromise) => {
    const child = spawn(executable, args, { shell: false, stdio: ['ignore', 'ignore', 'pipe'], windowsHide: true });
    const stderr: Buffer[] = [];
    const timer = setTimeout(() => {
      child.kill('SIGKILL');
      rejectPromise(new Error(`docker ${args[0] ?? ''} did not finish within ${String(timeoutMs)}ms`));
    }, timeoutMs);
    child.stderr.on('data', (chunk: Buffer) => {
      stderr.push(chunk);
    });
    child.on('error', (error: Error) => {
      clearTimeout(timer);
      rejectPromise(error);
    });
    child.on('close', (code) => {
      clearTimeout(timer);
      resolvePromise({ exitCode: code ?? 1, stderr: Buffer.concat(stderr).toString('utf8') });
    });
  });
}

export interface EnsureImageOptions {
  /** The Docker executable. Defaults to `docker` on PATH. */
  readonly executable?: string;
  /** How long a build may take. Installing the CLI pulls from npm. */
  readonly timeoutMs?: number;
}

/**
 * Builds the image if the daemon does not already hold the tag, and returns
 * the tag.
 *
 * Building on the host is deliberate: the host's network is the developer's
 * own, and the container this produces reaches only what the sandbox's egress
 * allowlist grants it. Nothing from the repository is copied in, so a stale
 * image cannot serve a task an old copy of the tree — the workspace arrives
 * at run time as the sandbox's one writable mount.
 */
export async function ensureImage(options: EnsureImageOptions = {}): Promise<string> {
  const executable = options.executable ?? 'docker';
  const timeoutMs = options.timeoutMs ?? 600_000;
  const tag = imageTag();

  const present = await docker(executable, ['image', 'inspect', tag], 60_000).catch((error: unknown) => {
    refuse('image', `the Docker daemon could not be reached to look for ${tag}: ${String(error)}`);
  });
  if (present.exitCode === 0) return tag;

  const built = await docker(
    executable,
    [
      'build',
      '--build-arg', `BASE=${BASE_IMAGE}`,
      '--build-arg', `CLI_VERSION=${CLI_VERSION}`,
      '--tag', tag,
      imageContext(),
    ],
    timeoutMs,
  ).catch((error: unknown) => {
    refuse('image', `building ${tag} did not finish: ${String(error)}`);
  });
  if (built.exitCode !== 0) {
    refuse('image', `building ${tag} failed with exit code ${String(built.exitCode)}: ${built.stderr.trim()}`);
  }
  return tag;
}

/**
 * One refusal type for the driver, shaped like the sandbox's: a `layer` names
 * which control declined, so a conformance assertion can require the right
 * refusal rather than merely some error. A test that accepts any throw passes
 * when the daemon is down, the image is missing, or the code has a typo, and
 * proves nothing about what it claims to cover (I5).
 */
export type DriverRefusalLayer =
  /** No sandbox provider, or one that did not provision the handle in the request. */
  | 'provider'
  /** The session authenticated with something other than the placeholder this driver set. */
  | 'credential'
  /** The image could not be built or is not present. */
  | 'image'
  /** A tool the request grants is not one this driver declares (I4). */
  | 'grant'
  /** The CLI could not be run, exited without a result, or produced output this driver cannot read. */
  | 'invocation'
  /** A capability the request needs is not one this driver declares. */
  | 'capability';

export class DriverRefusal extends Error {
  override readonly name = 'DriverRefusal';
  constructor(
    readonly layer: DriverRefusalLayer,
    message: string,
  ) {
    super(message);
  }
}

export function refuse(layer: DriverRefusalLayer, message: string): never {
  throw new DriverRefusal(layer, message);
}

===== packages/drivers/codex/src/tools.ts =====
/**
 * The tool inventory: every tool this driver can offer a task, and the one
 * setting of the pinned CLI that turns each on or off (D-R26-03).
 *
 * A constant rather than a probe, because `validateToolGrants` runs before
 * any task starts. It is held honest the other way round: before every task
 * the driver reads the tools the session's request actually carries
 * (D-R26-02), and the suite grants every shape and requires the request to
 * hold exactly that set. A CLI upgrade that adds, renames, or regroups a tool
 * fails the inspection rather than widening or narrowing what policy can
 * grant, which is why the version in `image.ts` is exact.
 *
 * A group is the tools one setting governs. The CLI offers all of a group or
 * none of it, so a grant naming part of one is refused: the session would
 * otherwise hold the rest, which nobody granted (I4).
 */

/** How the CLI is told to offer a group: a feature flag, or which of the two catalogs it reads (D-R26-04). */
export type ToolLever = { readonly kind: 'feature'; readonly feature: string } | { readonly kind: 'catalog' };

export interface ToolGroup {
  readonly tools: readonly string[];
  readonly lever: ToolLever;
}

export const TOOL_GROUPS: readonly ToolGroup[] = [
  // `exec_command` runs a command and `write_stdin` writes to one it left running. One feature governs both.
  { tools: ['exec_command', 'write_stdin'], lever: { kind: 'feature', feature: 'shell_tool' } },
  // No setting governs it: the catalog's `apply_patch_tool_type` does.
  { tools: ['apply_patch'], lever: { kind: 'catalog' } },
  { tools: ['view_image'], lever: { kind: 'feature', feature: 'view_image' } },
  { tools: ['get_goal', 'create_goal', 'update_goal'], lever: { kind: 'feature', feature: 'goals' } },
];

/**
 * Every tool a grant may name, sorted. Not here, and always off: `web_search`,
 * which OpenAI runs and bills per call outside the usage the relay reads;
 * `request_user_input`, which asks a person nobody provides; `tool_search` and
 * the multi-agent tools, which are out of scope (D-R26-03).
 */
export const DECLARED_TOOLS: readonly string[] = TOOL_GROUPS.flatMap((group) => group.tools).sort((a, b) => a.localeCompare(b));

/** Tools whose use runs a command in the sandbox. */
const COMMAND_TOOLS = new Set(['exec_command', 'write_stdin']);

export function isCommandTool(name: string): boolean {
  return COMMAND_TOOLS.has(name);
}

/** The groups a grant names, or the reason it cannot be honoured exactly. */
export function groupsFor(tools: readonly string[]): { readonly groups: readonly ToolGroup[] } | { readonly refusal: string } {
  const granted = new Set(tools);
  const undeclared = [...granted].filter((tool) => !DECLARED_TOOLS.includes(tool)).sort((a, b) => a.localeCompare(b));
  if (undeclared.length > 0) {
    return { refusal: `the task grants ${undeclared.map((t) => `'${t}'`).join(', ')}, which this driver does not declare` };
  }
  const groups: ToolGroup[] = [];
  for (const group of TOOL_GROUPS) {
    const held = group.tools.filter((tool) => granted.has(tool));
    if (held.length === 0) continue;
    if (held.length < group.tools.length) {
      const rest = group.tools.filter((tool) => !granted.has(tool));
      return {
        refusal:
          `the task grants ${held.map((t) => `'${t}'`).join(', ')} without ${rest.map((t) => `'${t}'`).join(', ')}, ` +
          'and the CLI offers those tools together or not at all',
      };
    }
    groups.push(group);
  }
  return { groups };
}

/** A provider that records every exec and runs none, for refusals that must happen before anything starts. */
function inertProvider(): { provider: SandboxProvider; execs: number } {
  const state = { execs: 0 };
  const provider = {
    id: 'inert',
    provision: () => Promise.reject(new Error('not used')),
    destroy: () => Promise.reject(new Error('not used')),
    capabilities: () => {
      throw new Error('not used');
    },
    exec: () => {
      state.execs += 1;
      return Promise.reject(new Error('an exec was attempted'));
    },
  } as unknown as SandboxProvider;
  return {
    provider,
    get execs() {
      return state.execs;
    },
  };
}

function refusalOf(body: () => unknown): Promise<DriverRefusal> {
  return Promise.resolve()
    .then(body)
    .then(
      () => {
        throw new Error('expected a refusal');
      },
      (error: unknown) => {
        if (!(error instanceof DriverRefusal)) throw error;
        return error;
      },
    );
}

===== packages/drivers/codex/test/harness.ts =====
/**
 * What this package's tests share: a real container on the pinned image, and,
 * for the paid assertions, a real relay holding a real credential.
 *
 * **Every test here needs a Docker daemon, and the paid ones an
 * `OPENAI_API_KEY`. They fail without either and are never skipped**: an
 * assertion that skipped itself would leave the registry reporting a claim on
 * the strength of a test that did not run (the reason `local-sandbox.ts` and
 * the Claude Code driver's harness give).
 *
 * The free tests use a sandbox with no relay and no route out. The inspection
 * (D-R26-02) runs entirely on the sandbox's loopback, so they read the request
 * a session would send, on the real CLI, without a key and without a model.
 */
import { execFile } from 'node:child_process';
import { randomUUID } from 'node:crypto';
import { chmod, mkdir, mkdtemp, rm, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { dirname, join } from 'node:path';
import { promisify } from 'node:util';
import { afterAll, expect } from 'vitest';
import type { Budget, CompiledRole, RoleId, TaskId, TaskRequest } from '@olympus-ai/core';
import type { ExecOptions, ExecResult, LocalDockerProvider, MeterReading, SandboxHandle, SandboxProvider, SandboxSpec } from '@olympus-ai/sandbox';
import { CodexDriver, MODEL_CREDENTIAL, MODEL_RELAY, ensureImage, parseEvents, type CodexDriverOptions } from '../src/index.js';

const run = promisify(execFile);

/** Where the host's credential is read from, to be handed to the provider and from there to the relay alone. */
export const HOST_CREDENTIAL_VARIABLE = 'OPENAI_API_KEY';

/** Where the workspace mount lands, and where the driver runs. */
export const WORKDIR = '/workspace';

/**
 * Per sandbox, enforced by its relay. The prices are the long-context ceiling
 * (D-R26-06), so a dollar here buys about half of what the list suggests; one
 * session of the pinned CLI sends a system prompt of some tens of thousands of
 * tokens, so this holds a test's few sessions with room, and stops a runaway.
 */
export const BUDGET: Budget = { maxTokens: 2_000_000, maxCostUsd: 1, maxWallClockMs: 300_000 };

/** A role whose instructions a session can be seen to receive. */
export const PROBE_ROLE: CompiledRole = {
  role: 'builder' as RoleId,
  instructions: 'You are the builder role of a test harness. Do exactly what the message asks and nothing more.',
  sha256: '0'.repeat(64),
};

/** The credential, or a failure naming what is missing. Read per call, so a test that unsets it sees it gone. */
export function credential(): string {
  const value = process.env[HOST_CREDENTIAL_VARIABLE];
  if (value === undefined || value.trim() === '') {
    throw new Error(
      `${HOST_CREDENTIAL_VARIABLE} is not set. The driver's paid assertions are proven against a real model call, ` +
        'so they refuse rather than skip without a credential: a claim asserted by a test that did not run is worse than one reported pending.',
    );
  }
  return value;
}

/** What this file's model calls used, as the CLI reported each, printed so a CI log says where the money went. */
const spent = { calls: 0, inputTokens: 0, cachedTokens: 0, outputTokens: 0 };

function recordCost(stdout: string): void {
  const usage = parseEvents(stdout).usage;
  if (usage === undefined) return;
  spent.calls += 1;
  spent.inputTokens += usage.inputTokens;
  spent.cachedTokens += usage.cachedInputTokens;
  spent.outputTokens += usage.outputTokens;
  console.log(
    `[model-cost] ${expect.getState().currentTestName ?? '(outside a test)'}: in ${String(usage.inputTokens)} (cached ${String(usage.cachedInputTokens)}), out ${String(usage.outputTokens)}`,
  );
}

afterAll(() => {
  if (spent.calls === 0) return;
  console.log(`[model-cost] file total: ${String(spent.calls)} sessions, in ${String(spent.inputTokens)} (cached ${String(spent.cachedTokens)}), out ${String(spent.outputTokens)}`);
});

/** The CLI's own account of the sessions one sandbox ran, beside what its relay counted. */
export interface SessionCounts {
  inputTokens: number;
  cachedTokens: number;
  outputTokens: number;
}

/** Every paid sandbox's reading and the CLI's account of it, kept for the meter control. */
export const meteredSessions: Array<{ readonly test: string; readonly reading: MeterReading | Error; readonly cli: SessionCounts }> = [];

export interface Harness {
  readonly driver: CodexDriver;
  readonly provider: LocalDockerProvider;
  readonly handle: SandboxHandle;
  /** The host directory behind the workspace mount. */
  readonly workspaceDir: string;
  /** The Vault root the provider was given, which no mount may be, sit inside, or contain (I1). */
  readonly vaultDir: string;
  /** The image the sandbox runs, for a test that provisions its own. */
  readonly image: string;
  /** The stable prefix every task of this harness shares, nonce included. */
  readonly stablePrefix: string;
  request(overrides?: Partial<TaskRequest>): TaskRequest;
  /** Every exec the driver made, in order. */
  readonly execs: ReadonlyArray<{ readonly cmd: readonly string[]; readonly env: Readonly<Record<string, string>> | undefined }>;
  /** Watches the driver's execs: `enter` runs as one starts and returns what to run when it ends. */
  observeExec(enter: (sandbox: SandboxHandle) => () => void): void;
  /** `count` more sandboxes like `handle`, each over its own workspace, torn down with the harness. */
  provisionMore(count: number): Promise<SandboxHandle[]>;
  /** Writes a file into the workspace, as an agent of an earlier seat could have. */
  plant(path: string, content: string): Promise<void>;
}

export interface HarnessOptions {
  /** Give the sandbox a relay holding the host's credential. Paid tests only. */
  readonly relay: boolean;
  readonly driver?: Partial<Omit<CodexDriverOptions, 'provider'>>;
}

export function spec(image: string, workspaceDir: string, relay: boolean): SandboxSpec {
  return {
    image,
    mounts: { workspace: { source: workspaceDir, target: WORKDIR, mode: 'rw' }, others: [] },
    // No egress at all: the relay, when there is one, is the sandbox's one route (P12).
    egress: { mode: 'deny-all', allow: [] },
    ...(relay ? { relay: { ...MODEL_RELAY, paths: [...MODEL_RELAY.paths], budget: { maxTokens: BUDGET.maxTokens, maxCostUsd: BUDGET.maxCostUsd } } } : {}),
    limits: { cpus: 2, memoryMb: 2048, pids: 512, wallClockMs: 600_000 },
    // The image's own `node` user. The workspace is opened to every uid below, as the Claude Code harness does.
    user: { uid: 1000, gid: 1000 },
  };
}

export async function withDriver<T>(options: HarnessOptions, body: (h: Harness) => Promise<T>): Promise<T> {
  const secret = options.relay ? credential() : undefined;
  const image = await ensureImage();
  const base = await mkdtemp(join(tmpdir(), 'codex-driver-'));
  const workspaceDir = join(base, 'workspace');
  const vaultDir = join(base, 'vault');
  await mkdir(workspaceDir, { recursive: true });
  await mkdir(vaultDir, { recursive: true });
  await chmod(workspaceDir, 0o777);
  const { LocalDockerProvider: Provider } = await import('@olympus-ai/sandbox');
  const provider = await Provider.create({
    vaultPaths: [vaultDir],
    ...(secret === undefined ? {} : { credentials: { [MODEL_CREDENTIAL]: secret } }),
  });
  const handle = await provider.provision(spec(image, workspaceDir, options.relay));
  const extra: SandboxHandle[] = [];
  const counts = new Map<SandboxHandle, SessionCounts>();
  const countsFor = (h: SandboxHandle): SessionCounts => {
    let c = counts.get(h);
    if (c === undefined) {
      c = { inputTokens: 0, cachedTokens: 0, outputTokens: 0 };
      counts.set(h, c);
    }
    return c;
  };
  let watcher: ((sandbox: SandboxHandle) => () => void) | undefined;
  const execs: Array<{ cmd: readonly string[]; env: Readonly<Record<string, string>> | undefined }> = [];
  const watched: SandboxProvider = {
    id: provider.id,
    provision: (s: SandboxSpec) => provider.provision(s),
    destroy: (h: SandboxHandle) => provider.destroy(h),
    capabilities: () => provider.capabilities(),
    exec: async (h: SandboxHandle, cmd: string[], o?: ExecOptions): Promise<ExecResult> => {
      const leave = watcher?.(h);
      execs.push({ cmd: [...cmd], env: o?.env });
      try {
        const result = await provider.exec(h, cmd, o);
        recordCost(result.stdout);
        const usage = parseEvents(result.stdout).usage;
        if (usage !== undefined) {
          const c = countsFor(h);
          c.inputTokens += usage.inputTokens;
          c.cachedTokens += usage.cachedInputTokens;
          c.outputTokens += usage.outputTokens;
        }
        return result;
      } finally {
        leave?.();
      }
    },
  };
  const driver = new CodexDriver({ provider: watched, workdir: WORKDIR, ...options.driver });
  const stablePrefix = `Run identifier: ${randomUUID()}. It is the same for every task of this run.`;
  const test = expect.getState().currentTestName ?? '(outside a test)';
  const harness: Harness = {
    driver,
    provider,
    handle,
    workspaceDir,
    vaultDir,
    image,
    stablePrefix,
    request: (overrides: Partial<TaskRequest> = {}): TaskRequest => ({
      taskId: 'probe' as TaskId,
      role: PROBE_ROLE,
      stablePrefix,
      variableSuffix: 'Reply with the single word: ready',
      tier: 'fast',
      tools: [],
      sandbox: handle,
      timeoutMs: 300_000,
      budget: BUDGET,
      ...overrides,
    }),
    execs,
    observeExec: (enter) => {
      watcher = enter;
    },
    provisionMore: async (count: number): Promise<SandboxHandle[]> => {
      for (let i = 0; i < count; i += 1) {
        const dir = join(base, `workspace-${String(extra.length)}`);
        await mkdir(dir, { recursive: true });
        await chmod(dir, 0o777);
        extra.push(await provider.provision(spec(image, dir, options.relay)));
      }
      return extra.slice(-count);
    },
    plant: async (path: string, content: string): Promise<void> => {
      const target = join(workspaceDir, path);
      await mkdir(dirname(target), { recursive: true });
      await writeFile(target, content);
    },
  };
  try {
    return await body(harness);
  } finally {
    for (const h of [handle, ...extra]) {
      const reading = await provider
        .destroy(h)
        .then((t) => t.meter)
        .catch((error: unknown) => (error instanceof Error ? error : new Error(String(error))));
      if (options.relay) meteredSessions.push({ test, reading, cli: countsFor(h) });
    }
    await rm(base, { recursive: true, force: true });
  }
}

/** Runs `docker` on the host and returns its stdout. For reading a container from outside it. */
export async function dockerOut(args: string[]): Promise<string> {
  const { stdout } = await run('docker', args, { maxBuffer: 64 * 1024 * 1024 });
  return stdout;
}

/** The settings that turn the workspace's instruction sources off. The control removes exactly these. */
const INSTRUCTION_SETTINGS = new Set([
  'project_doc_max_bytes=0',
  `projects.${JSON.stringify(WORKDIR)}.trust_level="untrusted"`,
  'skills.include_instructions=false',
  'skills.bundled.enabled=false',
]);

/**
 * The control (R23): the driver's own invocation, less its instruction
 * settings, through the same capture. It shows the plants are where the pinned
 * CLI reads, so their absence from the driver's request means something.
 * No model is called.
 */
export async function controlRequestBody(h: Harness, tools: readonly string[]): Promise<string> {
  const result = groupsFor(tools);
  if ('refusal' in result) throw new Error(result.refusal);
  const args = cliArgs(WORKDIR, 'gpt-5.6-luna', h.request({ tools: [...tools] }), result.groups);
  const kept: string[] = [];
  for (let i = 0; i < args.length; i += 1) {
    const arg = args[i] ?? '';
    const next = args[i + 1] ?? '';
    if (arg === '-c' && INSTRUCTION_SETTINGS.has(next)) {
      i += 1;
      continue;
    }
    kept.push(arg);
  }
  if (kept.length !== args.length - 2 * INSTRUCTION_SETTINGS.size) throw new Error('the control did not find every instruction setting in the driver argv');
  const nonce = randomUUID();
  const exec = await h.provider.exec(h.handle, inspectArgv(WORKDIR, nonce, kept), {
    env: { [KEY_VARIABLE]: KEY_PLACEHOLDER, [CAPTURE_SOURCE_VARIABLE]: CAPTURE_SOURCE, [CAPTURE_NONCE_VARIABLE]: nonce, NO_PROXY: '127.0.0.1', no_proxy: '127.0.0.1' },
  });
  const captured = capturedFrom(exec.stdout, nonce);
  if ('missing' in captured) throw new Error(`the control could not be captured: ${captured.missing}; stderr: ${exec.stderr}`);
  return captured.requests.map((r) => r.body ?? '').join('\n');
}
